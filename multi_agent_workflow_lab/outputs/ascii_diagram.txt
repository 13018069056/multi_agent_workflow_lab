+----------------------------------------------------------------------+
|                         状态转移序列图                            |
+----------------------------------------------------------------------+
|   1. start        | 实现一个 add(a, b) 函数，返回两个数字之和。                   |
|       | 继续执行 ↓                                                  |
|   2. planner      | 形成四步执行计划                                      |
|       | 继续执行 ↓                                                  |
|   3. programmer   | 生成第 1 版代码                                     |
|       | 继续执行 ↓                                                  |
|   4. reviewer     | 当前代码使用了减法，不符合 add 函数需求。                       |
|       | 继续执行 ↓                                                  |
|   5. router       | 审查未通过，返回 Programmer                           |
|       | 失败重试 ↓                                                  |
|   6. programmer   | 生成第 2 版代码                                     |
|       | 继续执行 ↓                                                  |
|   7. reviewer     | 代码逻辑符合加法需求。                                   |
|       | 继续执行 ↓                                                  |
|   8. tester       | 测试通过                                          |
|       | 成功通过 ↓                                                  |
|   9. checkpoint   | 检查点自动批准，工作流结束                                 |
+----------------------------------------------------------------------+
